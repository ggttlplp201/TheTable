# Fidelity Correction Report

## Outcome

The production match shell is now a single full-viewport first-person table. Authoritative game state and command dispatch are unchanged. Player actions are presented through the physical hand, scene intents, compact HUD controls, and focused overlays. The previous dashboard is available only in development with `?debug=1`.

## Required self-audit

1. Gameplay fits in one viewport: yes, enforced by CSS and browser geometry assertions.
2. No normal page scrolling during a match: yes; only focused overlay bodies may scroll.
3. Player feels seated at the table: yes; active players use the seated reference framing.
4. Player can look around: yes; desktop pointer-look and mobile drag-to-look are active outside overlays.
5. Other players are physical: yes; role-tinted character models occupy seats.
6. Inventories are physical: yes; public items occupy six slots at each seat and the own hand is directly actionable.
7. Chests are physical: yes; both chest models track public state and emit scene intents.
8. Use, Trade, and Threat are integrated: yes; all open over the live table and use visual choice tiles.
9. Objective is a private contract: yes; it uses an on-demand parchment surface.
10. Shops share the game world: yes; table stock remains physical and market focus views overlay the scene.
11. Debug UI is hidden from production: yes.
12. Production resembles the standalone references immediately: yes at the architecture, composition, palette, HUD, and interaction-presentation levels; final numeric side-by-side scoring is unautomated as noted above.
13. Obsolete mechanics are excluded: yes; client presentation binds only final-rule state and commands.
14. Mobile preserves shared-table context: yes; every focus panel leaves the table visible behind it.
