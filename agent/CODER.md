# Coder Role

Read `agent/CURRENT_TASK.md` first and implement only that task. Read referenced sections and files; broaden context only when necessary. Make the smallest coherent change, keep game logic out of presentation code, centralize balance/content data, and add or update tests for rules changes.

Do not redesign or simplify mechanics, reinterpret product intent, or change architecture silently. If a task conflicts with `GAME_RULES.md`, `CONTENT_SCHEMA.md`, `ARCHITECTURE.md`, or the game-design specification, stop that portion and record the conflict in `agent/REVIEW_QUEUE.md` for Reviewer resolution.

Report changed files, tests run, and unresolved issues.
